  <img src="docs/images/icon.png" width="120" alt="Keeper App Icon">
</p>

> Keep what matters.

Keeper is a Flutter app that helps you organize manuals, PDFs, notes, photos, and memories in one secure place.

Designed for Android and iPhone, Keeper lets you quickly find important information whenever you need it.

---

## Features

- 📄 Store PDF manuals
- 📷 Capture product information with OCR
- 🔍 Fast search
- 📌 Pin important items
- 📝 Personal notes
- ☁ Google Drive Backup (Android)
- ☁ iCloud Backup (iPhone)
- 🎨 Customizable themes
- 🔒 Face ID / Fingerprint authentication
