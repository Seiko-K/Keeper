あなたらしくKeeper

取扱説明書、PDF、写真、メモ、思い出。 必要な情報をひとつにまとめて、自分らしく整理できる Android・iPhone対応アプリです。

Keeperについて お問い合わせ

必要な情報を、迷わず見つける。

Keeperは、情報を保存するだけでなく、 後から気持ちよく探して使えることを大切にしています。

📄

PDFを端末へ保存

取扱説明書や大切なPDFをKeeper内へ保存し、 オフラインでも確認できます。

📷

型番をOCRで読み取り

カメラで型番を読み取り、面倒な手入力を減らします。 認識結果は確認してから利用できます。

🔍

マニュアル検索

メーカーや型番から取扱説明書の候補を探し、 自分で選んだ情報だけをKeeperできます。

📌

ピン留めと並べ替え

よく使う情報を上部へ固定し、 自分の使いやすい順番へ整理できます。

🌙

テーマとダークモード

複数のテーマカラーとライト・ダーク表示に対応。 自分らしい見た目で使えます。

🔒

端末認証でロック

Face ID、Touch ID、指紋認証など、 端末の認証機能を利用してKeeperを守れます。

大切なデータをクラウドへ。

バックアップは、利用者がボタンを押したときだけ実行されます。

Android

Google Driveのアプリ専用領域へ保存。 バックアップの整合性をSHA-256で確認します。

iPhone / iPad

iCloudのCloudKit Private Databaseへ保存。 復元前にサイズとSHA-256を検証します。
